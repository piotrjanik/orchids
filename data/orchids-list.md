# Orchid Species List

This file contains a list of orchid species to generate care guides for. The content generation script reads this file and creates detailed care information for each species.

## Format

Each orchid entry should follow this format:
- **Common Name** (*Scientific Name*)
  - Custom YouTube videos (optional): URL1, URL2
  - Custom websites (optional): URL1, URL2

## Orchid List

### Moth Orchid (*Phalaenopsis*)
Popular beginner orchid with long-lasting flowers.

### Cattleya Orchid (*Cattleya*)
Known for large, fragrant flowers. Often called the "Queen of Orchids."

### Lady's Slipper Orchid (*Paphiopedilum*)
Distinctive pouch-shaped flowers, terrestrial or semi-terrestrial growth.

### Dancing Lady Orchid (*Oncidium*)
Produces sprays of small, often yellow flowers resembling dancing figures.

### Dendrobium Orchid (*Dendrobium*)
Large genus with diverse growing requirements and flower forms.

## Adding Custom Resources

You can add custom YouTube videos and websites for any orchid species by adding them below the species name:

### Example with Custom Resources

### Moth Orchid (*Phalaenopsis*)
- Videos: https://www.youtube.com/watch?v=your-video-id
- Websites: https://example.com/phalaenopsis-care

These custom resources will be prioritized in the generated care guide.
